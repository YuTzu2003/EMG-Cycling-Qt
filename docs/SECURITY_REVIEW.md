# 資安檢查紀錄

Codex Security 已對本次 Qt／Flask 轉型的工作樹執行差異掃描（掃描 ID：`2dc513e6-486f-4b91-bb66-57af2073df34`）。掃描涵蓋 78 個檢查項、68 個檔案，提出四項問題：區網 HTTP 傳輸、登入無次數限制、踏板時間跨度造成大量記憶體配置，以及角度資料圈數跨度造成大量運算。

掃描完成後已在程式中處理這四項問題：網站只允許本機綁定並要求手機經 HTTPS 反向代理連線、代理模式使用 Secure Cookie、登入限制 15 分鐘內每個來源最多五次失敗、踏板資料限制 24 小時、角度事件依輸入列數運算。Qt 的非同步封存另有一項可能誤刪其他騎乘資料的競態，也已固定每次騎乘的封存 ID。

本紀錄描述掃描後的修改；原始 Codex Security 報告保留掃描當時的發現。後續以九項自動測試驗證網站認證、HTTPS 模式、CSV、分析、比較與封存側別傳遞。已在本機 SQL Server `RehabPatients-ylh` 建立三張網站資料表，確認既有 3 名病人及 6 筆測試可讀取；以臨時病人驗證原始 CSV 寫入、讀取與清理，另以臨時測試驗證 `Sessions`、`EMGData`、`PedalData`、`TrainerData` 寫入與清理。實體裝置收集與手機上的 TLS 憑證信任仍需在目標環境驗證。

網站目前使用單一共用密碼，適合受控團隊的內部使用；公開對外服務前，應加入個別帳號、權限與操作紀錄。
