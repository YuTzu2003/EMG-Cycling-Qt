# 系統使用操作說明

本文件對應 `uv run emg-cycling` 啟動的 PySide6 桌面介面。環境安裝見 [README](README.md)，資料計算定義見 [資料取得、同步與分析方法](DATA_PIPELINE.md)。

## 1. 建立本次測試

1. 開啟「設定」，填入受試者 **ID** 和姓名，勾選本次要收集的 EMG、阻力計、踏板；至少選一種。
2. EMG：確認 Trigno SDK Server 已啟動，輸入 Server IP（本機通常是 `127.0.0.1`），按「測試 EMG 連線」。使用「設定感測器對應」檢查每個 Slot 的肌肉名稱及左右側。
3. 阻力計／踏板：按「重新掃描」，選取裝置並「設定為阻力計」或「設定為踏板」，再按各裝置的「連線」。P715 以左踏板主裝置連線；右踏板不可單獨當作主裝置。
4. 在「設定 → 資料輸出」選擇 CSV 與攝影機影片共用的輸出資料夾；再到「收集資料」確認連線燈號與收集時間。時間設為 0 表示由操作者手動停止。

## 2. 量測 EMG 基準

在「收集資料」按「測量 20 秒基準」，輸入本次動作、姿勢、阻力與踏頻等操作說明，維持相同動作至倒數結束。前 10 秒作為穩定期捨棄，後 10 秒的濾波訊號各計算一個通道 RMS。完成後各肌肉列會顯示基準值；無效通道保留原有有效基準。也可用「匯入基準 CSV」讀取本程式已錄製且有完整前 20 秒的 EMG CSV，或在感測器對應編輯器手動設定基準並記錄原因。

後續騎乘必須維持相同感測器、肌肉／側別對應、取樣率及濾波設定，才會顯示基準差異。若是「無基準值」、「基準不相容」或「資料不足」，請先檢查對應與量測品質；系統不會用 0 代替缺失值。基準動作及顏色門檻是研究設定，尚需臨床端確認。

## 3. 開始騎乘與查看本次摘要

在「收集資料」按「開始收集資料」，可即時查看 EMG 波形／每條肌肉 RMS、踏板功率／左右平衡及訓練台阻力。切到「本次摘要」的「騎乘總覽」可查看有效肌肉數、各肌肉平均／最大 RMS、踏板平均功率、訓練台平均阻力和時間圖。停止後摘要會保留，並在輸出資料夾保存 `*.analysis.json`。

若本次同時錄到 EMG 與踏板 CSV，停止後會自動切到「後續分析 → 踩踏角度分析」，在背景計算前後段 RMS、MDF、相位曲線與逐圈圖。進度及無法分析的原因會顯示在該頁。系統會依共同資料長度選取開頭與結尾的分析時段；共同資料不足 35 秒時不會分析。分析會估計 EMG 時鐘比例，起點偏移使用 0 秒；未經影片校正的踏板 CSV 顯示的是相對踩踏相位。分析完成後，右上角的「匯出角度分析」才會啟用。

分析既有檔案時，在「後續分析」右上角分別按「匯入原始 EMG」和「匯入踏板 CSV」，選擇同次騎乘的兩個原始檔；目前載入的檔名會統一顯示在頁面左上角。兩者都完成匯入後，系統會自動切到「踩踏角度分析」並開始計算。需要調整前後段比較時間、EMG 時鐘比例或起點偏移時，使用右上角的「角度分析設定」；儲存後會自動重新分析。角度分析頁沒有左側操作區或重複的檔案提示。「匯入踏板 CSV」也接受已校正角度 CSV，此類檔案只有角度分析，沒有功率摘要。若重新匯入另一筆 EMG，需重新選擇對應的踏板 CSV，以免混用不同騎乘。一般 FIT 只有功率與踏頻，沒有曲柄事件資料，不能用於此角度分析。

預設肌肉比較值是 `目前 RMS − 基準 RMS`（mV）；勾選「顯示 normalized RMS」後為 `目前 RMS ÷ 基準 RMS`（倍）。這兩種計算描述電活動相對於測得基準的變化，不能直接解釋為力量增減。

「EMG 相對阻力時間偏移」預設為 0 秒。若兩設備有相同可辨識事件，可輸入正／負偏移：**正值將 EMG 往較晚的時間移動**。修改歷史紀錄的偏移會更新其分析檔；原始 CSV 不變。沒有共同事件時應維持 0 並將結果視為近似對齊。

「踏板數值與功率區間」會在收集中定時更新，顯示 NP、IF、最佳 5 秒功率、資料涵蓋率及 FTP 功率區間；「踏板圖表」可查看功率、踏頻、左右平衡隨時間變化。兩頁亦可查看右上角匯入的踏板 CSV 紀錄。修改 FTP 後，指標和區間立即重算。資料不足 30 秒時 NP／IF／TSS 顯示 `--`；資料涵蓋率低於 95% 時不顯示全程 TSS。踏板封包頻率不會被強制重採樣成 EMG 或訓練台頻率。

## 4. 從資料庫比較兩次 RMS

1. 到「設定」完成 SQL Server 測試連線，並確認同一病人至少有兩次已保存的 EMG 測試。
2. 按「資料庫 RMS 比較」，在「測試比較」頁選擇病人後按「載入量測」。
3. 任選兩筆不同紀錄作為量測 A、量測 B；選單顯示測試日期、時間長度與固定阻力。
4. 設定前段與後段秒數，預設各 30 秒，按「比較 RMS」。右腳、左腳會分頁呈現；每條肌肉左側顯示兩次前／後段平均 RMS，右側顯示各自從 0 秒起算的完整 RMS 曲線。

數值直接使用資料庫的每秒 `AvgRMSmV` 計算，**不除以個人基準值**。曲線不會為了對齊而裁切或拉伸；缺少某條肌肉時會顯示「無資料」，不以 0 代替。若指定秒數超過任一次量測長度，畫面會提示縮短時段。

目前資料庫資料表沒有保存 EMG 取樣率與濾波參數，因此畫面會提示操作者確認兩次使用相同收集設定。肌肉名稱與左右側以保存時的 `MuscleName` 配對；名稱不一致時會各自顯示為缺少另一筆資料。

## 5. 歷史資料與報表

Use "Export HTML Report" to create a standalone report with patient information, test settings, EMG trends, pedal and trainer summaries, and data-quality notes.

本程式收集的踏板資料會保存為 CSV，並另外產生 FIT 活動檔。畫面上的「匯入踏板 CSV」使用本程式的原始踏板 CSV；FIT 活動檔不包含角度分析需要的完整曲柄事件資料。
