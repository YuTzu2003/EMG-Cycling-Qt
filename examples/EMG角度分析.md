# 各踏板角度的肌群活化分析（Test2）：剛開始 vs 快結束

> 專案已在「本次摘要 → 踩踏角度分析」整合這套同步、逐圈分析與匯出流程。原始範例程式仍保留供對照。GUI 依設定頁的感測器 `-L`／`-R` 側別計算，Test2 檔案請先按下方第 1 節貼片紀錄核對側別。使用未經影片校正的本專案 Pedal CSV 時，GUI 顯示「相對踩踏相位」，不能將 0° 當成上死點。操作步驟見專案根目錄 README。

資料：`EMG.csv`（Delsys Trigno，14 通道）+ `pedal_angles_from_pedal_angle_py.csv`（由 Pedal.csv 重建、經影片校正的左右踏板角度）。
騎乘條件：阻力段 4，功率約 100 W、踏頻約 52 rpm，連續 300 s。

## 1. 先解決的時間軸問題（重要）

- **EMG.csv 的 `time_seconds` 用的是 1925.9 Hz，但實際取樣率約 2000 Hz**（2001.8 Hz）。
  用 EMG 爆發（burst）序列與 Pedal.csv 的 263 次曲柄事件逐圈比對：EMG 時間軸比 session 時間快 3.94 %，
  300 s 累積差 12 s；修正（`t_session = time_seconds / 1.0394`）後，爆發時刻與曲柄事件的線性擬合殘差只有 0.05 s。
  **之後用這份 EMG 做任何與 Pedal/影片的對齊都必須先做這個修正。**
- 兩檔的起點假設相同（session 0 = EMG 0）。在此假設下，所有肌群的尖峰角度比文獻典型值平均早約 25°
  （雙腳一致），可能是真實差異，也可能是約 0.08 s 的起點差（在 BLE 通知抖動的 ±0.2 s 不確定度內）。
  因此**絕對角度有約 ±25° 的系統性不確定度；但「開始 vs 結束」的比較不受影響**（同一偏移）。
- 左右腳指派：各肌群成對感測器的尖峰相差 180°；以影片校正的右踏板角度判斷，
  **右腳 = S02 BF、S04 VM、S06 RF、S08 VL、S10 TA、S13 GAS、S16 SOL；左腳 = S01、S03、S05、S07、S11、S12、S14**。
  （若實際貼片與此相反，代表 Pedal 與 EMG 起點差了半圈 0.56 s；請以貼片紀錄為準。）

## 2. 處理流程

1. 帶通 20–450 Hz（4 階 Butterworth, 零相位）+ 60 Hz notch → 全波整流 → 6 Hz 低通線性包絡。
2. 每個通道以整段第 99 百分位正規化（% of session peak；無 MVC）。
3. 以該側踏板角度（0° = 上死點、90° = 最前、180° = 下死點、270° = 最後）切 24 個 15° 區間，逐圈求平均 → 每圈一條活化曲線。
4. 「剛開始」= session 5–65 s（約 52 圈），「快結束」= 240–300 s（約 53 圈）。比較：每圈 RMS（µV）、尖峰角度、活化占比（>20 % 調變幅度的角度比例）、中位頻率 MDF（疲勞指標），Mann–Whitney 檢定；另對整段做線性趨勢。
5. 機械輸出對照：功率 103 → 97 W、踏頻 52.5 → 53.3 rpm（幾乎不變），左右功率比 48/52 → 53/47。

## 3. 各角度的活化型態（整段平均，見 `emg_angle_heatmap.png`、`emg_vs_angle_start_vs_end.png`）

| 肌群 | 主要活化角度（該側踏板） | 尖峰 | 備註 |
|---|---|---|---|
| 股直肌 RF | 300° → 90°（上死點前後） | ~0–10° | 跨上死點，雙關節肌，最早啟動 |
| 股內側肌 VM / 股外側肌 VL | 315° → 105° | 30–45° | 下踩主力；雙腳型態幾乎相同 |
| 股二頭肌 BF | 90° → 200° | 100–150° | 下踩後段到下死點 |
| 腓腸肌 GAS | 60° → 180° | 120–130° | 下死點前（踝蹠屈） |
| 比目魚肌 SOL | 45° → 150° | 80–105° | 比腓腸肌略早 |
| 脛前肌 TA | 240° → 360° | 300–320° | 上提段（踝背屈），下踩時幾乎關閉 |

順序 RF → VM/VL → SOL → GAS → BF → TA，與踩踏文獻的典型順序一致（Hug & Dorel 2009 等），只是整體約早 25°（見第 1 節）。

## 4. 剛開始 vs 快結束（`emg_start_vs_end_summary.csv`）

| 肌群 | 每圈 RMS 變化 右 / 左 | MDF 變化 右 / 左 (Hz) | 活化占比 右 / 左 | 尖峰角度位移 右 / 左 |
|---|---|---|---|---|
| RF 股直肌 | **+60 % / +51 %** | −10 / **−18** | 0.61→0.66 / 0.61→0.69 | −15° / −18° |
| VM 股內側肌 | **+38 %** / +20 % | −5 / −3 | 不變 | −16° / −14° |
| VL 股外側肌 | **+57 %** / +20 % | −8 / 0 | 不變 | −10° / −14° |
| BF 股二頭肌 | +44 % / +48 % | −12 / −11 | 0.62→0.70 / 不變 | −17° / −4° |
| GAS 腓腸肌 | +28 % / +41 % | −14 / **−25** | 0.50→0.60 / 0.43→0.60 | +12° / −4° |
| SOL 比目魚肌 | +39 % / +8 % | −13 / −6 | 0.50→0.65 / 0.34→0.39 | −10° / −19° |
| TA 脛前肌 | +12 % / +13 % | −9 / −12 | 0.54→0.60 / 0.47→0.55 | −16° / −10° |

所有 RMS 與多數 MDF 變化 p < 0.01（Mann–Whitney，每組約 52 圈）。

### 主要發現

1. **典型的神經肌肉疲勞型態**：功率與踏頻幾乎不變，但 14 個通道每圈 RMS 全部上升（+8 % ～ +60 %），同時 13/14 個通道的中位頻率下降（−3 ～ −25 Hz）。振幅上升 + 頻譜左移 = 為了維持同樣輸出要徵召更多/更大的運動單位、傳導速度下降。趨勢圖（`emg_fatigue_trends.png`）顯示大部分變化發生在前 100 s，之後趨於平緩。
2. **右腳疲勞比左腳明顯**：右 VL +57 %、VM +38 %、SOL +39 % vs 左 +20 %、+20 %、+8 %；同時右腳功率佔比由 52 % 降到 47 %。右腳用更多肌電卻輸出更少功率 → 右腳效率下降較多，左腳補償。
3. **活化範圍變寬、尖峰稍提前**：結束時股直肌幾乎整圈都保持 30–40 % 的背景活化（開始時在 135–270° 只有 ~15 %）；腓腸肌/比目魚肌在 180–270°（上提段）出現開始時沒有的平台（約 40 %）；脛前肌在 180–270° 也提早啟動。這代表協同/拮抗肌共同收縮增加、肌肉「關不乾淨」，是疲勞與動作控制變差的常見表現。尖峰角度普遍提前 10–18°，但這個量級接近時間對齊的不確定度（±10°），不宜過度解讀；右腓腸肌反而延後 12° 是唯一例外。
4. **股二頭肌、股直肌 MDF 下降最多**（−10～−18 Hz），腓腸肌左側 −25 Hz；股外側肌左側幾乎沒變。

### 注意事項
- S01（左 BF）訊號很小（RMS 4–7 µV，正規化基準 8.7 µV），可能貼片接觸不佳，其結果可信度較低。S08（右 VL）在 180° 附近結束段有一次大尖波（最大 2 mV），SD 帶因此變寬。
- 沒有 MVC，所以 % 值是相對整段尖峰，不能跨肌群比較絕對強度，只能比較型態與時間變化。
- 絕對角度有 ±25° 的系統性不確定度（第 1 節）；若要精確到 10° 以內，需硬體同步（曲柄磁簧/霍爾開關接 Trigno 類比通道）。

## 6. 程式用法：先同步、再分析（兩支程式）

```
# 0) 先由 Pedal.csv 產生角度檔（前一階段的程式）
python pedal_angle.py convert Pedal.csv -o pedal_angles.csv --rate 100

# 1) 同步：EMG.csv + 角度檔 → 每個 EMG 樣本都帶踏板角度
python emg_pedal_sync.py EMG.csv pedal_angles.csv -o emg_synced.csv
#    選項：--scale auto|1.0|1.0394   EMG 時間比例（auto 由爆發序列對曲柄事件自動估）
#          --offset 0|auto|<秒>       EMG 0 s 對應的 session 時間（預設 0 = 同時起始）
#          --ref-channels S03_...,S07_...  指定估時鐘用的參考通道（預設自動挑 4 個）
#          --no-raw                   不輸出 129 MB 的全取樣率檔；--envelope-rate 100 另存 100 Hz 包絡線版
#    輸出：emg_synced.csv、emg_synced_envelope_100Hz.csv、sync_report.json、sync_check.png

# 2) 分析：逐圈 × 角度 × 左右腳，剛開始 vs 快結束
python emg_angle_analysis.py emg_synced.csv --report sync_report.json --out emg_out --start 5 65 --end 240 300
#    --left S01_...,S03_...  可手動覆蓋左腳通道；--bins 24；--norm 99
```

`emg_pedal_sync.py` 做的事：濾波與包絡線 → 在參考通道找每圈的爆發尖峰 → 與角度檔的曲柄事件（圈數跨過整數）配對 → 線性迴歸求 EMG 時間比例 a → 以 a 換算 session 時間、把右/左踏板角內插到每個 EMG 樣本 → 用成對感測器尖峰相差 180° 與文獻模板判左右腳（寫在 sync_report.json 的 `leg_assignment`）。
`sync_check.png` 上圖的殘差應該零均值、無趨勢（Test2：±0.1 s）；下圖參考通道對右踏板角度應呈清楚單峰。

起點偏移（offset）無法只靠 EMG 與角度資料本身決定：各肌群爆發相位不同，迴歸截距 b 含相位。預設假設同時起始；`--offset auto` 用文獻模板估整體偏移（Test2 估 −0.06 s，±25° 不確定度）；有硬體同步脈衝時用 `--offset <秒>` 最準。
